# Cisco NetFlow Monitoring & Traffic Analysis Lab

## Overview

This project demonstrates the implementation and analysis of Cisco NetFlow using Cisco Packet Tracer. The lab focuses on generating network traffic, monitoring flow records, and analyzing session-based communication through a simulated NetFlow collector.

The objective of this lab is to gain practical exposure to traffic visibility, flow monitoring, and network behavior analysis commonly used in SOC environments, network monitoring, and cybersecurity operations.

---

## Objectives

### Part 1 — Observe NetFlow Flow Records

* Generate ICMP traffic using ping requests
* Observe one-directional NetFlow records
* Analyze source/destination IP addresses
* Review packet counters, byte counts, and timestamps
* Understand flow creation behavior

### Part 2 — Analyze Full Session Traffic

* Observe HTTP request and response flows
* Analyze bidirectional session behavior
* Monitor TCP/IP communication using NetFlow
* Understand ephemeral ports and session tracking
* Investigate protocol-specific flow records
